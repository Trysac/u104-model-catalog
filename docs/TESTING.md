# Testing\n\nTests reside in `tests/test_model_catalog.py` and cover the following:\n\n- Input validation: Ensuring invalid catalog files (bad formats, missing fields, duplicate IDs, invalid types, float prices) raise `CatalogError` with descriptive paths like `models[0].entries[0].input_per_mtok`.\n- Versioning logic: Verifying that `get()` and `query()` return the correct entry for a given `at` date (including the `not_valid_at` error case).\n- Query filtering: Ensuring filters (provider, min_context, capability, price) correctly narrow results and return them in the expected order.\n- Size limiting: Checking that files over `max_bytes` raise `too_large` while others load correctly.\n- CLI: Testing that the `__main__` entry point returns correct exit codes (0, 1, 2) and formats output correctly.
