# Architecture\n\n## Design\n\n`model_catalog` treats LLM specifications as versioned data. It implements a strict validation layer that parses JSON into an in-memory `Catalog` object. All currency values use `Decimal` to avoid binary floating-point errors. Point-in-time lookups operate on a "latest valid <= at" basis, ensuring deterministic results across historical data. No system clock or network calls occur within the library.
